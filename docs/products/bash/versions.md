# Bash 版本演进

GNU Bash（Bourne-Again SHell）是绝大多数 Linux 发行版与容器镜像的默认 Shell。从 4.0 到 5.2，Bash 持续增强了关联数组、安全参数转换与现代化内置变量。

## 核心版本演进与关键里程碑

### Bash 5.2（2022 年 9 月）

**主要功能与架构演进：**

- 全新重构的命令替换（Command Substitution）解析引擎，大幅提升深层嵌套 `$(...)` 的解析准确度
- 新增参数变换操作符 `${var@k}` / `${var@K}`（以键值对形式展开关联数组）
- 优化了交互式行编辑（Readline 8.2）与大量后台作业并发调度

**工程影响与选型建议：**

> 当前主流现代 Linux 发行版（如 Ubuntu 24.04, Fedora 38+）的标配版本。

### Bash 5.1（2020 年 12 月）

**主要功能与架构演进：**

- 引入 `$SRANDOM` 内置环境变量：由系统安全随机数（/dev/urandom）驱动，产生 32 位高质量随机数
- 关联数组支持复合键赋值语法与参数转换优化

**工程影响与选型建议：**

> 避免了旧版 `$RANDOM`（15 位伪随机）在脚本中容易产生碰撞的安全漏洞。

### Bash 5.0（2019 年 1 月）

**主要功能与架构演进：**

- 引入 `$EPOCHSECONDS` 与 `$EPOCHREALTIME` 原生时间戳变量（微秒级精度），无需频繁 fork `date` 进程
- 修复历史已久的 `glob` 与信号处理死锁问题

**工程影响与选型建议：**

> 脚本性能与微秒级日志时间戳打点的重大改进。

### Bash 4.4（2016 年 9 月）

**主要功能与架构演进：**

- 引入参数变换 `${var@Q}`：自动将变量内容转义为适合安全重用的 Shell 引号字符串
- 增强对关联数组未赋值访问时的空安全处理

**工程影响与选型建议：**

> 防范命令注入与安全构造动态命令的关键工具。

### Bash 4.0（2009 年 2 月）

**主要功能与架构演进：**

- 正式引入关联数组（`declare -A array`），支持基于字符串键名的哈希字典映射
- 引入 `globstar`（`shopt -s globstar`），支持 `**` 递归匹配多层子目录
- 引入 `mapfile` / `readarray`：单行内置命令高速将文件流读取为数组

**工程影响与选型建议：**

> Bash 语言从简单胶水脚本跃升为结构化编程语言的历史性里程碑。

## 兼容性与跨平台提示
- macOS 默认自带的 Bash 停留在 **Bash 3.2**（由于 GPLv3 协议限制），因此在 macOS 上编写复杂脚本时，严禁使用 Bash 4.0+ 特性（如关联数组 `declare -A`、`**` 递归匹配），或需通过 Homebrew 安装最新版 Bash。
