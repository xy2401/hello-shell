> **参考官方文档**：[GNU Bash 官方发布说明](https://www.gnu.org/software/bash/manual/)

## 版本定位

- **发布时间：** 2016 年 9 月
- **维护状态：** 历史版本或兼容基线；实际维护状态以官方页面为准
- **产品线：** GNU Bash

## 核心变化

**主要功能与架构演进：**

- 引入参数变换 `${var@Q}`：自动将变量内容转义为适合安全重用的 Shell 引号字符串
- 增强对关联数组未赋值访问时的空安全处理

**工程影响与选型建议：**

> 防范命令注入与安全构造动态命令的关键工具。

## 兼容与迁移

- 在目标版本运行语法检查和真实脚本回归，覆盖展开、管道、重定向、陷阱与退出码。
- 分别验证交互配置和非交互脚本；不要从登录 Shell 推断 `/bin/sh` 的实际实现。
- 部署脚本应明确最低版本，并为系统自带旧版本保留兼容路径。

## 版本确认

不要根据安装包名称或容器标签推断实际版本，应在目标环境执行：

```bash
bash --version
```

生产记录至少应包含完整版本输出、操作系统或运行时基线、架构，以及所用客户端或驱动版本。
