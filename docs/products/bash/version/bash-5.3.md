# Bash 5.3

> **参考官方文档**：[GNU Bash 官方发布说明](https://lists.gnu.org/archive/html/bug-bash/2025-07/msg00005.html)  
> 本页依据正式 Release 与现有仓库版本证据，整理 Bash 5.3 的关键变化、兼容边界和升级检查。

## 版本定位

- **发布时间：** 2025 年 7 月
- **维护状态：** 截至 2026-08-27 的当前重要版本线
- **产品线：** GNU Bash

## 核心变化

- 新增可在当前 Shell 环境执行的命令替换形式，减少传统子 Shell 带来的状态隔离
- 扩展 `GLOBSORT`、`BASH_MONOSECONDS` 等变量，并修正多项解析、补全与作业控制问题
- 构建基线提升到 C90 与 POSIX.1-1990

## 兼容与迁移

- 升级前应回归命令替换、补全脚本、陷阱与作业控制；不要把 5.3 专属语法下放到仍运行 5.2 的系统脚本。

## 版本确认

不要根据安装包名称或容器标签推断实际版本，应在目标环境执行：

```bash
bash --version
```

生产记录至少应包含完整版本输出、操作系统或运行时基线、架构，以及所用客户端或驱动版本。
