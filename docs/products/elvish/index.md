# Elvish 分卷

> 本页结论：Elvish 将现代函数式编程理念与强类型数据流注入命令行，是一门专为极客与开发者打造的优雅 Shell 语言。

## 一句话定位

**极具编程语言素养的现代化函数式 Shell。**

- 由 Go 语言编写，跨平台且体积小巧；
- 管道流处理数据结构（列表、字典甚至函数）而非文本；
- 提供强大的异常捕获与纯粹的函数式编程体验。

## 核心特色

1. **强类型数据管道**：
   与 Nushell 类似，Elvish 的管道传递真实数据结构。但它的语法设计更倾向于“现代编程语言”而非“SQL 表格查询”，支持 Lambda 表达式和高阶函数。
2. **完善的异常处理**：
   打破了 POSIX 靠 `$?` 退出码猜错误的窘境，Elvish 提供类似现代语言的异常捕获与抛出机制。
