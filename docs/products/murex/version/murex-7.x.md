# Murex 7.x

> **参考官方文档**：[Murex 官方发布说明](https://github.com/lmorg/murex/releases)  
> 本页依据正式 Release 与现有仓库版本证据，整理 Murex 7.x 的关键变化、兼容边界和升级检查。

## 版本定位

- **发布时间：** 2025–2026 年
- **维护状态：** 截至 2026-08-27 的当前重要版本线
- **产品线：** Murex

## 核心变化

**主要功能与架构演进：**

- 持续扩展类型感知管道和结构化数据格式
- 改进自动补全、终端集成和跨平台行为
- 保持与传统命令调用习惯的折中

**工程影响与选型建议：**

> 按官方 Release 页面锁定具体 7.x 版本，并测试 JSON、YAML、CSV 管道和配置文件。

## 兼容与迁移

- 在目标版本运行语法检查和真实脚本回归，覆盖展开、管道、重定向、陷阱与退出码。
- 分别验证交互配置和非交互脚本；不要从登录 Shell 推断 `/bin/sh` 的实际实现。
- 部署脚本应明确最低版本，并为系统自带旧版本保留兼容路径。

## 版本确认

不要根据安装包名称或容器标签推断实际版本，应在目标环境执行：

```bash
murex -version
```

生产记录至少应包含完整版本输出、操作系统或运行时基线、架构，以及所用客户端或驱动版本。
