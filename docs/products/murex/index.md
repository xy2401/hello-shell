# Murex 总览

> 本页结论：Murex 在保持传统 POSIX 命令行使用直觉的同时，为管道注入了对现代数据格式的强支持，是一个极其贴合运维实战的折中派。

## 一句话定位

**既保留 POSIX 习惯，又能操作 JSON 的实用派数据 Shell。**

- 不打破传统 Bash 用户的基本肌肉记忆；
- 原生识别并支持对 JSON、CSV、YAML 等数据在管道中做查询过滤；
- 带有智能的自动补全引擎。

## 核心特色

1. **平缓的学习曲线**：
   不想像 Nushell 那样彻底颠覆命令行习惯？Murex 提供了非常类似 Bash 的操作体验，但赋予了你处理现代后端数据的能力。
2. **类型感知管道**：
   当你 `cat` 一个 JSON 文件并通过管道传递给下一个命令时，Murex 知道它是一个 JSON，并能直接应用强类型的数据提取语法。

*(注：本页为特色介绍扩展，暂未收录入标准 9 大统一任务快照矩阵)*

## 适用边界

适合带类型的数据管道探索；语法及命令生态独立，现有统一任务快照不覆盖此 Shell。
