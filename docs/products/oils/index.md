# Oils for Unix 总览

> 本页结论：Oils（原 Oil Shell）旨在解决 Bash 沉重的历史包袱，同时兼顾向后兼容，是未来 Unix 底层 Shell 最具潜力的接班人。

## 一句话定位

**致力于终结 Bash 且向后兼容的新一代工业级 Shell。**

- 双解析器架构：OSH (兼容 Bash) + YSH (全新的现代语法)；
- 抛弃 Bash 的空格漏洞、引文陷阱，引入 Python 风格的严谨解析；
- 提供原生 JSON 数据支持。

## 核心特色

1. **无缝继承历史资产 (OSH)**：
   能完美运行现存几十年的脏乱差 Bash/POSIX 脚本，让你无需为了升级环境而重写海量的老旧脚本库。
2. **现代化的新语法 (YSH)**：
   在编写新脚本时，YSH 语言像 Python 一样严谨可读。它抛弃了 `$var` 不加双引号就会分词的古怪规则，大大降低了编写健壮系统脚本的门槛。

*(注：本页为特色介绍扩展，暂未收录入标准 9 大统一任务快照矩阵)*

## 适用边界

适合比较 OSH 的兼容路线与 YSH 的语言设计；两种模式需分别学习，现有统一任务快照不覆盖全部特性。
