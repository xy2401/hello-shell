# rc 1.7

> **参考官方文档**：[rc 官方发布说明](https://github.com/rakitzis/rc/releases)  
> 本页依据正式 Release 与现有仓库版本证据，整理 rc 1.7 的关键变化、兼容边界和升级检查。

## 版本定位

- **发布时间：** 历史稳定线
- **维护状态：** 截至 2026-08-27 的当前重要版本线
- **产品线：** rc

## 核心变化

**主要功能与架构演进：**

- 延续 Plan 9 rc 的列表、函数和极简语法模型
- Unix 移植版长期保持低频维护
- 与 POSIX sh 不是语法兼容关系

**工程影响与选型建议：**

> 迁移时应把 rc 脚本视为独立语言，不能直接交给 `/bin/sh`。

## 兼容与迁移

- 在目标版本运行语法检查和真实脚本回归，覆盖展开、管道、重定向、陷阱与退出码。
- 分别验证交互配置和非交互脚本；不要从登录 Shell 推断 `/bin/sh` 的实际实现。
- 部署脚本应明确最低版本，并为系统自带旧版本保留兼容路径。

## 版本确认

不要根据安装包名称或容器标签推断实际版本，应在目标环境执行：

```bash
rc -c 'echo $version'
```

生产记录至少应包含完整版本输出、操作系统或运行时基线、架构，以及所用客户端或驱动版本。
