# Nushell 总览

> 本页结论：Nushell 颠覆了传统 Unix 文本流，将终端重塑为结构化数据处理的现代平台，是目前系统级特色 Shell 中最具变革性的明星项目。

## 一句话定位

**把终端变成强大的数据表格引擎。**

- 用结构化数据（Table、List、Record）彻底取代传统的纯文本管道；
- 基于 Rust 构建，兼顾极高执行性能与现代化的开发者人体工程学；
- 跨平台原生（Windows / macOS / Linux 体验完全一致）。

## 核心特色

1. **结构化管道流**：
   抛弃 `awk`/`sed`/`grep` 复杂的文本正则切分。在 Nushell 中，执行 `ls` 或 `ps` 返回的是真正的数据表格，你可以像 SQL 一样查询：
   `ls | where size > 10mb | sort-by modified | select name size`
2. **万物皆可解析**：
   内置引擎支持原生读取并解析外部的 `JSON`、`CSV`、`YAML`、`TOML`，自动转化为表格统一查询。
3. **Rust 风格生态**：
   出色的类型系统和友好的错误提示，告别传统 Shell 猜不透的隐式错误。

*(注：本页为特色介绍扩展，暂未收录入标准 9 大统一任务快照矩阵)*

## 适用边界

适合结构化表格管道；不是 POSIX Shell 的直接替代，现有统一任务快照不覆盖此 Shell。
