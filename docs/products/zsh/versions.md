# Zsh 版本演进

Zsh（Z Shell）是 macOS 默认交互式 Shell，同时也是高级开发者广泛使用的生产力终端工具。

## 核心版本演进与关键里程碑

### Zsh 5.9（2022 年 5 月）

**主要功能与架构演进：**

- 全面提升针对 POSIX 2024 标准的兼容性与 UTF-8 字符宽度精准计算
- 重构动态补全引擎内部缓存，降低大型 Git 仓库下的 Prompt 渲染延迟

**工程影响与选型建议：**

> 当前 macOS 与主流 Linux 发行版的标准稳定基准。

### Zsh 5.8（2020 年 2 月）

**主要功能与架构演进：**

- 优化了多行语法高亮（Syntax Highlighting）与行编辑器（ZLE）的事件循环集成
- 改进浮点数数学运算精度与管道进程退出码捕获（`$pipestatus`）

**工程影响与选型建议：**

> 高度定制化终端主题（如 Powerlevel10k）的极速运行基石。

### Zsh 5.0（2012 年 12 月）

**主要功能与架构演进：**

- 引入全新的模块化体系与 `zsh/datetime` 高性能内置时间模块
- 全面提升对 POSIX 语法的兼容模式（`emulate sh`）

**工程影响与选型建议：**

> 5.x 现代 Zsh 架构的确立。

## 脚本可移植性注意
- Zsh 默认数组下标从 **1** 开始（不同于 Bash 从 0 开始），在编写跨 Shell 脚本时推荐显式使用 `emulate -L sh`。
