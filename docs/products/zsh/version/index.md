# Zsh 版本演进

Zsh（Z Shell）是 macOS 默认交互式 Shell，同时也是高级开发者广泛使用的生产力终端工具。

## 版本索引

### [Zsh 5.9](./zsh-5.9)

- **发布时间：** 2022 年 5 月
- **版本重点：** 全面提升针对 POSIX 2024 标准的兼容性与 UTF-8 字符宽度精准计算。

### [Zsh 5.8](./zsh-5.8)

- **发布时间：** 2020 年 2 月
- **版本重点：** 优化了多行语法高亮（Syntax Highlighting）与行编辑器（ZLE）的事件循环集成。

### [Zsh 5.0](./zsh-5.0)

- **发布时间：** 2012 年 12 月
- **版本重点：** 引入全新的模块化体系与 zsh/datetime 高性能内置时间模块。

## 脚本可移植性注意
- Zsh 默认数组下标从 **1** 开始（不同于 Bash 从 0 开始），在编写跨 Shell 脚本时推荐显式使用 `emulate -L sh`。
