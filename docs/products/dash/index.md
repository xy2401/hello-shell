# Dash 总览

> 本页结论：Dash 不追求交互体验，而是极致打磨执行性能，它是支撑全球无数服务器系统底层稳定运转的“幕后英雄”。

## 一句话定位

**把执行速度和轻量化推向绝对极值的后台王者。**

- Debian Almquist Shell 的缩写，追求极致的 POSIX 标准合规；
- 剥离了一切用于交互的复杂特性（高亮、历史、智能补全）；
- Ubuntu/Debian 系统 `/bin/sh` 的默认硬链接对象。

## 核心特色

1. **不可思议的性能**：
   体积不到 Bash 的十分之一，由于没有历史遗留的沉重特性包袱，执行系统脚本的速度通常是 Bash 的 3~4 倍。
2. **严格的 POSIX 合规**：
   它是检验一个脚本是否真的具备“跨平台 POSIX 兼容性”的最佳试金石。如果你的脚本能在 Dash 跑通，那就基本能在任何 Unix 系统跑通。

*(注：本页为特色介绍扩展，暂未收录入标准 9 大统一任务快照矩阵)*

## 适用边界

适合 POSIX sh 脚本与精简执行；不支持 Bash 数组等扩展，交互功能也不是主要目标。
