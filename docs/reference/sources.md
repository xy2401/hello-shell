# 官方资料基线

本页列出本站解释 Shell 语义时优先采用的 E1 官方资料。实际行为仍以仓库内对应的 `demos/**/*.out.txt` 快照为准，引用和判定规则见[证据政策](./evidence-policy)。

## Shell 与命令解释器

- **Bash**：[GNU Bash Reference Manual](https://www.gnu.org/software/bash/manual/)
- **Zsh**：[Zsh Documentation](https://zsh.sourceforge.io/Doc/)
- **Fish**：[fish shell documentation](https://fishshell.com/docs/current/)
- **CMD**：[Windows commands](https://learn.microsoft.com/windows-server/administration/windows-commands/windows-commands)
- **PowerShell**：[PowerShell documentation](https://learn.microsoft.com/powershell/)
- **Python**：[Python 3 documentation](https://docs.python.org/3/)

## 浏览器运行环境

- **JUST-BASH**：[vercel-labs/just-bash](https://github.com/vercel-labs/just-bash)
- **BusyBox**：[BusyBox](https://busybox.net/)
- **Pyodide**：[Pyodide documentation](https://pyodide.org/)
- **V86**：[copy/v86](https://github.com/copy/v86)
- **container2wasm**：[ktock/container2wasm](https://github.com/ktock/container2wasm)

## 使用方式

1. 用官方资料确认语法、选项和设计约定。
2. 用本仓库快照确认指定版本与平台上的实际输出。
3. 两者出现差异时，在结论中同时标明资料来源和快照路径，并优先陈述实际输出。
